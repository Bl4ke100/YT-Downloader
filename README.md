# KRONOS 4K • YouTube Downloader

An ultra-modern, high-speed YouTube video and audio downloader built with **FastAPI**, **yt-dlp**, and native **FFmpeg 8.1**. Designed with a monochrome luxury aesthetic (shades of deep black, obsidian, and crisp white).

## Features
- **4K UHD & High FPS Support**: Download videos up to 4K (2160p, 60fps), 2K (1440p), 1080p FHD, 720p HD, and more.
- **Audio Extraction**: Studio-grade MP3 (320kbps), original AAC/M4A, and lossless WAV with metadata embedding.
- **Instant Preview**: Video thumbnail, duration, view count, channel name, and quality breakdown with file size estimations.
- **Real-Time Progress**: Live download speed (MB/s), percentage, total downloaded size, and FFmpeg multiplexing status.
- **Direct Browser Download**: Automatically prompts file download in the browser and provides a local folder reveal option.

## Quick Start

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Launch the Application
Simply double-click `start.bat` or run:
```bash
python run.py
```
This starts the local server at `http://127.0.0.1:5000` and automatically opens your web browser.
